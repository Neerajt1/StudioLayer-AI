OBJECTIVE

StudioLayer AI is evolving from a Virtual Try-On application into an AI Fashion Styling Platform.

The objective of this sprint is NOT to improve image rendering.

The objective is to build the Intelligence Layer that understands garments and intelligently completes outfits before rendering.

This sprint creates the decision engine only.

Rendering behaviour MUST remain exactly the same.

PART 6

Decision Engine

Build a deterministic Rule Engine.

The Rule Engine makes the first decision.

GPT is OPTIONAL.

GPT should only be used when

• no suitable rule exists

OR

• Rule Engine confidence is low.

The application must function correctly using only the Rule Engine.

GPT is an enhancement layer, not a dependency.

PART 9

Architecture Principles

Rendering MUST NEVER decide styling.

Styling MUST NEVER decide rendering.

The Intelligence Layer produces ONE structured outfit object.

Example

{
  "styleMode": "ecommerce_catalog",
  "uploadedGarment": {
    "category": "bottom",
    "subcategory": "jeans"
  },
  "recommendedOutfit": {
    "top": "white crew neck t-shirt",
    "footwear": "white sneakers",
    "accessories": [
      "brown belt"
    ]
  }
}

The rendering engine simply consumes this object.

Do NOT duplicate styling logic inside rendering code.

The Fashion Knowledge Base must remain the single source of truth.

The architecture must allow future replacement of the Rule Engine without modifying the renderer.
