SL-016 — Pre-Styled Base Model Library

Production Implementation Sprint

StudioLayer AI Rendering Pipeline v1.1

Source Basis: Derived from the approved SL-015 investigation. This sprint implements Option B (Pre-Styled Base Model Library) only.

Objective

Implement a Pre-Styled Base Model Library that intelligently selects category-specific base model images for FASHN rendering.

This sprint must:

Preserve the current FASHN integration.

Preserve BirefNet preprocessing.

Preserve backward compatibility.

Introduce no API breaking changes.

Not implement FLUX integration.

Not implement prompt-driven rendering.

Design Principles

Existing Identity Library remains intact.

User-selected identities always override automatic selection.

Base Models are internal rendering assets.

Architecture must support future expansion (styles, seasons, occasions, regions).
